# Análise de desempenho: Fibonacci Recursivo x Fibonacci com Matriz
## Como rodar o programa
### Pré-requisitos:
* Python
* Biblioteca NumPy
* Biblioteca Matplotlib

### Executando Testes:

Para rodar os testes, primeiramente, baixe `main.py`, depois pelo terminal vá até a pasta do arquivo e digite o seguinte comando:

Windows:
```bash
  py main.py
```
Mac/Linux:
```bash
  python3 main.py
```
